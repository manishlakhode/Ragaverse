## ⚡ Getting Started

**1. Clone the repo**
```bash
git clone https://github.com/manishlakhode/Ragaverse.git
cd Ragaverse
```

**2. Create & activate a virtual environment** (recommended)
```bash
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
```

**3. Install dependencies**
If a requirements.txt file exists, install packages with:
```bash
pip install -r requirements.txt
```
